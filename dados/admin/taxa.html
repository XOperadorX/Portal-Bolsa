Instalação e procedimentos de administração
  1. Execute instalar-taxas.sql no SQL Editor do projeto Supabase.
  2. Acesse pelo login do portal. A permissão para publicar é validada pelo banco para a sessão autenticada.
  3. Entre nesta página, altere os campos e revise a simulação. Clique em publicar para salvar globalmente.
  4. Para desfazer uma alteração, preencha os valores anteriores e publique uma nova versão. O histórico mantém o registro de cada publicação.

Sem a tabela global ou sem conexão, os jogos continuam usando os padrões anteriores. Esta página informa a indisponibilidade e não confirma uma gravação que falhou.
