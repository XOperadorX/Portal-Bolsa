⚡ Ordem de Prioridade para Registro

🔴 PRIORIDADE 1 — Registrar IMEDIATAMENTE
  • Itens Lendários — qualquer peça
  • Itens Épicos — Arma e Arma Secundária primeiro
  • Conjuntos faltando apenas 1 peça
🟡 PRIORIDADE 2 — Registrar em seguida
  • Itens Raros (Azuis) — todas as peças
  • Épicos restantes: Armadura → Colar → Anel → Elmo → outros
  • Cinto e Selo (bônus extra acumulável)
🟢 PRIORIDADE 3 — Registrar por último
  • Itens Incomuns (Verdes) — quando sobrarem
  • Itens Comuns (Brancos) — só para completar; desmonte o resto

📊 SQL — Calcular Bônus Total

-- Soma todos os bônus do Codex do usuário
SELECT
  login,
  ataque_base + COALESCE(SUM((item->'bônus'->>'ataque')::numeric), 0) AS ataque_total,
  defesa_base + COALESCE(SUM((item->'bônus'->>'defesa')::numeric), 0) AS defesa_total,
  hp_max + COALESCE(SUM((item->'bônus'->>'hp')::numeric), 0) AS hp_max_total,
  COUNT(*) AS itens_registrados
FROM "Geral",
     jsonb_array_elements(itens) AS item
WHERE login = 'usuario_exemplo'
GROUP BY login;

🔄 SQL — Atualizar Atributos do Usuário

-- Recalcula atk/def/hp com bônus do Codex
WITH bonus AS (
  SELECT
    COALESCE(SUM((item->'bônus'->>'ataque')::integer), 0) AS atk,
    COALESCE(SUM((item->'bônus'->>'defesa')::integer), 0) AS def,
    COALESCE(SUM((item->'bônus'->>'hp')::integer), 0) AS hp
  FROM "Geral", jsonb_array_elements(itens) AS item
  WHERE login = 'usuario_exemplo'
)
UPDATE "Geral"
SET
  atk = ataque_base + (SELECT atk FROM bonus),
  def = defesa_base + (SELECT def FROM bonus),
  hp_max = hp_max + (SELECT hp FROM bonus),
  updated_at = CURRENT_TIMESTAMP
WHERE login = 'usuario_exemplo';

📋 SQL — Listar Itens Registrados

-- Exibe todos os itens do Codex em ordem de prioridade
SELECT
  item->>'nome' AS nome,
  item->>'tipo_peca' AS peca,
  item->>'raridade' AS raridade,
  item->>'tier' AS tier,
  (item->'bônus'->>'ataque')::integer AS bonus_atk,
  CASE WHEN (item->>'pode_descartar')::boolean 
       THEN '✅ Pode descartar' 
       ELSE '⚠️ Manter' END AS status
FROM "Geral", jsonb_array_elements(itens) AS item
WHERE login = 'usuario_exemplo'
ORDER BY
  (item->>'prioridade_registro')::integer ASC,
  (item->>'tier')::integer DESC;

💡 Regras de Negócio

  • Registro permanente: nunca remover itens do array — apenas marcar pode_descartar: true
  • Atributos dinâmicos: atk, def, hp_max = valor base + soma de todos os bônus
  • Conjuntos completos: quando todas as peças de um mesmo id_conjunto forem registradas → aplicar bônus extra de conjunto
  • Conta única: o Codex é por conta, não por personagem
