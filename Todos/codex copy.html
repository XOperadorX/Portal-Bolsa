ℹ️ O que é o Codex

É um sistema de coleção permanente: ao registrar um equipamento, você ganha bônus de atributos para TODOS os personagens da conta. Após registrar, venda ou desmonte o item — o bônus permanece.

Acesso

Menu → Codex → Equipamento

⚡ Ordem de Prioridade para Registro

🔴 PRIORIDADE 1 — Registrar IMEDIATAMENTE
  • ✅ Itens Lendários (Dourados) — qualquer peça
  • ✅ Itens Épicos (Roxos) — Arma e Arma Secundária primeiro
  • ✅ Conjuntos incompletos que faltam APENAS 1 peça para fechar
🟡 PRIORIDADE 2 — Registrar em seguida
  • ✅ Itens Raros (Azuis) — todas as peças
  • ✅ Épicos restantes: Armadura → Colar → Anel → Elmo → outros
  • ✅ Cinto e Selo (novos conjuntos — bônus acumulável extra)
🟢 PRIORIDADE 3 — Registrar por último
  • ✅ Itens Incomuns (Verdes) — apenas quando sobrarem
  • ✅ Itens Comuns (Brancos) — só para completar o progresso; desmonte o resto

💡 Dicas Práticas

  1. Regra de Ouro: Registre SEMPRE antes de vender, desmontar ou equipar em outro personagem — o bônus é permanente!
  2. Foco primeiro: Feche os conjuntos de nível mais alto primeiro. Um conjunto completo de Tier 15 > itens avulsos de Tier 20.
  3. Duplicatas: Tem 2 itens iguais? Registre um e desmonte o outro para obter Pó de Pedra Mágica.
  4. Itens de Evento: Atenção — alguns itens promocionais não podem ser registrados. Verifique antes de descartar.
  5. Encantamento: Itens já registrados podem ser encantados normalmente sem afetar o Codex — o registro é feito no item base.
  6. Conta toda: O progresso é único por conta. O que registrar com um personagem já vale para todos os outros.

⚠️ Resolução de Problemas Comuns

❌ "Vendi e perdi o bônus?" → NÃO! Após o registro, o item pode ser descartado que o bônus fica para sempre.

❌ "Não consigo registrar" → Verifique: (1) item já registrado? (2) é item de evento? (3) nível mínimo do personagem? (4) tem espaço no Codex?

❌ "Não vejo os valores subindo" → Os bônus são aplicados automaticamente. Clique no ícone 🔍 nos atributos para ver o detalhamento.

❌ "Mudei de servidor e sumiu?" → O Codex é vinculado à conta, não ao servidor. O progresso permanece em todos os servidores.
