✅ CORREÇÕES APLICADAS (12/10/2026)
================================================================================
Aplicadas nas versões mais recentes dos arquivos:

[1] Configuração Supabase centralizada
    - config.js carrega a chave pública e cria o cliente compartilhado
    - config-module.js mantém as exportações ESM do aplicativo
    - As páginas clássicas carregam config.js antes dos scripts locais

[2] .gitignore
    - Ignora node_modules/, platforms/, plugins/, www/ e hooks/
    - config.js é versionado para também funcionar no deploy

[4] index.html
    - Adicionado: validação t > 0 em sessaoValida() (evita session_timestamp corrompido)
    - Corrigido: fallback redireciona para noticias.html (NÃO login.html)
    - Impacto: elimina loop entre index ↔ login ↔ dashboard

[5] login.html
    - Corrigido: sessão só é salva APÓS aplicarRegeneracaoOffline()
    - Impacto: HP/MP/SM sempre atualizados antes do redirect

[6] admin.html
    - Corrigido: renomeado const supabase → supabaseDB (não sobrescreve window.supabase)
    - Corrigido: todas as chamadas .from(...) usam supabaseDB
    - Impacto: outras libs/scripts que usam window.supabase não quebram

[7] adm_cadastro.html
    - Adicionado: função hashSenha() (SHA-256, compatível com cadastro.html)
    - Corrigido: btnSalvarUsuario agora salva senha com hash
    - Corrigido: btnResetarSenha agora salva senha com hash
    - Impacto: senhas editadas no admin funcionam no login

[8] dashboard.html
    - Removido: import de REGEN_CONFIG (era importado mas nunca usado)
    - Corrigido: configurarEventosDosJogos() usa event delegation no #gamesGrid
    - Corrigido: gastarStaminaParaJogar() pega card via event.target.closest()
    - Impacto: elimina duplicação de listeners ao reconfigurar

[9] codex.html
    - Removido: <script src="...supabase..."> duplicado
    - Mantido: apenas importmap + import ESM
    - Impacto: uma única instância da lib Supabase carregada

[10] trocap.html
    - Adicionado: fallback numérico em criarTroca() para data.taxa e data.valor_liquido
    - Adicionado: fallback em abrirModalCodigo() (valida Number.isFinite)
    - Impacto: modal-resumo nunca exibe "NaN"

[11] manifest.json
    - Corrigido: name = "MM Quase Tudo — Central de Jogos"
    - Corrigido: short_name = "MMQuaseTudo"
    - Adicionado: start_url, display, orientation, icons
